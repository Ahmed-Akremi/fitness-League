# React Native port of the mobile app — design

Date: 2026-09-30 · Status: approved in chat

## Intent

React Native will replace the Flutter app (`apps/mobile`). The port is sliced: each sub-project ports a set of
features to `apps/mobile-rn` while the Flutter app keeps working untouched. The NestJS API does not change.

Sub-project 1 = core infrastructure + the Auth → Onboarding → Log workout (offline) → League loop.
Done when: sign in, log a workout offline, reconnect, it syncs and appears in the League; `typecheck` and `test`
pass under `pnpm -r`.

Later sub-projects port the remaining features (home, profile/settings, progress, goals, badges, social, feed,
notifications, battles, challenges, leagues, gyms, gym WODs, gym wars, moderation/proofs), reusing the core.

## Stack

Expo SDK 57 (managed, `expo-dev-client`), TypeScript strict, expo-router, TanStack Query (server state),
Zustand (session / locale / theme), expo-sqlite (outbox), expo-secure-store (refresh token),
@react-native-community/netinfo, socket.io-client, i18next + react-i18next, Jest (`jest-expo`) + React Native
Testing Library. `apps/mobile-rn/.npmrc` sets `node-linker=hoisted` for Metro.

## Core behaviour (identical to the Dart implementation)

- **ApiClient** — access token held only in memory; refresh token in secure storage. Concurrent 401s with
  `TOKEN_EXPIRED`/`TOKEN_INVALID` share ONE `/auth/refresh` call (server refresh tokens are single-use, so a
  second call would look like token theft). Each request is retried once, `/auth/*` never. A network failure
  during refresh keeps the stored token; a server refusal clears it. Sends `Accept-Language`; 20 s timeout via
  AbortController. The transport (`fetch`) is injectable (demo backend, tests).
- **WorkoutSyncService** — `Idempotency-Key = clientId`. On a network or timeout error during save the workout
  goes to the outbox; other errors are rethrown to the form. `flush()` posts `/workouts/sync` in batches of 50
  and maps each result: CREATED/REPLAYED removed, CONFLICT → conflict, REJECTED → rejected, anything else →
  rejected with the error code. Concurrent flushes share one run. Triggered when NetInfo comes back online
  while signed in, and after the session is restored.
- **Realtime** — socket.io on `<origin>/ws`, websocket transport, connected only while signed in, current
  access token re-sent on every reconnect attempt, battle subscriptions re-emitted on connect. Noop in demo.
- **Guard** — unknown → /splash; signed out → /login (public: login, register, forgot-password);
  `me` not loaded → /splash (with Retry on error); not onboarded → /onboarding; otherwise the tabs.

## Slice screens (sub-project 1)

Ported one to one (same fields, l10n keys, validation): splash, login, register, forgot password, onboarding,
Train (workout list + outbox banner with discard), Log workout (sport, date, duration, exercise cards with
sets, warm-up, HYROX full race sheet, notes), workout detail (+ points), League (national/region/gym/friends
scopes, cursor paging, around me). Home/Challenges show "coming in a later slice"; Profile shows Sign out.
Photo proofs are deferred to the moderation/proofs slice.

Endpoint payloads get small hand-written TS interfaces covering what the screens read.

## Theme, i18n, demo

- Theme tokens from `app_theme.dart` (graphite dark first, light variant, single accent `#C6F432` default,
  20px card radius), Barlow Condensed + Inter via expo-font. Small in-house components (Button, Card,
  TextField, Tabs, Toast).
- i18n: `.arb` → i18next JSON (`{x}` → `{{x}}`, ICU plurals → i18next `_one`/`_other` keys). Arabic forces RTL
  and reloads. Layouts use start/end only.
- Demo (`EXPO_PUBLIC_DEMO=true`): same `assets/demo/api.json` and matching rules as `demo_backend.dart`;
  in-memory outbox, Noop realtime.

## Errors

`ApiError` keeps the Dart kinds (`network`, `timeout`, `unauthenticated`, `client`, `server`) plus `status`,
the server problem `code`, field errors and the raw body. `ErrorView` / `errorMessage()` port
`error_text.dart`. Session expiry signs out and the guard redirects to login.

## Testing

Jest + RNTL with a fake transport. Ports of `api_client_test`, `workout_sync_test`, `login_test`,
`onboarding_test`, `log_workout_test`, `league_test`, `demo_mode_test`. Manual check on a device/emulator:
airplane mode → log → reconnect → synced → visible in League.

## Out of scope (sub-project 1)

Push notifications, image upload/proofs, EAS build/release config, removing Flutter.
