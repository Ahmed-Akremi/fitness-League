# Accueil : carrousel des compétitions et actualités — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Les admins publient des actualités (texte et/ou une photo) que les athlètes peuvent aimer, et l'Accueil montre les compétitions en cours dans un carrousel de bannières.

**Architecture:** Nouveau module NestJS `announcements` (tables `announcements` + `announcement_likes`, photo traitée comme les bannières), fan-out des notifications dans le worker via l'outbox ; page « Publications » dans le panneau admin ; sections « carrousel » et « Actualités » sur l'Accueil RN.

**Tech Stack:** NestJS + Prisma 6 + Postgres, sharp ; React + Vite (admin, vitest) ; Expo / React Native (jest-expo).

**Spec:** `docs/superpowers/specs/2026-10-06-home-news-design.md`

## Global Constraints

- Rôles qui publient : `ADMIN`, `SUPER_ADMIN` (jeton panneau, `@AdminApi()`).
- Texte ≤ 2000 caractères ; au moins texte ou photo ; une photo max ; PNG/JPEG/WebP ≤ 5 Mo → WebP ≤ 1440 px de large ; jamais de vidéo ; aucune route de commentaire.
- Notification `ANNOUNCEMENT` `{ announcementId, excerpt }` (80 car.) aux `role = USER`, `status = ACTIVE`, `deletedAt = null`, par lots de 1000.
- Carrousel : `GET /competitions?filter=CURRENT` = statut ∉ {DRAFT, FINISHED, CANCELLED}, tri `eventStart` asc.
- Accueil : salutation → LP saison → carrousel → rangs → ma salle → objectif → raccourcis → Actualités → bouton séance.
- Migration additive ; i18n en/fr/ar ; testID existants conservés.
- Commandes : API `pnpm test:unit`, `pnpm test:integration`, `pnpm lint`, `pnpm typecheck` (dans `apps/api`) ; admin `npx vitest run`, `npx tsc --noEmit` ; RN `npx jest --maxWorkers=2`, `npx tsc --noEmit`.

## Review Focus

- Like concurrent ou répété (double tap) : jamais deux lignes, jamais d'erreur 500 (upsert / `skipDuplicates`).
- Publication supprimée : disparaît du fil, `PUT like` → 404, son fichier n'est plus servi.
- Image très haute ou très petite : jamais agrandie, proportions conservées ; l'app réserve la hauteur (`imageWidth/imageHeight`) sans saut de mise en page.
- Texte avec espaces seulement : traité comme vide (422 si pas de photo).
- Arabe (RTL) : en-tête de carte, compteur ❤️ et points du carrousel suivent le sens de lecture.
